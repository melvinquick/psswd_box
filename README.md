## About

This app was created to give people an easy way to generate passwords completely locally on their machine. It doesn't rely on a cloud service, or any information leaving the local machine whatsoever.

## Installation

The installer sets up a dedicated venv and creates a desktop shortcut.

```
curl -s https://raw.githubusercontent.com/melvinquick/psswd_box/main/install.py | python3 -
```
